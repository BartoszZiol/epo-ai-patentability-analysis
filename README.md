# Czy można opatentować oprogramowanie i sztuczną inteligencję w Europie?

**Projekt edukacyjny z prawa patentowego**  
**Autor:** Bartosz Ziółkowski  
**Data:** 16 listopada 2026 r.  
**Zakres:** Europejska konwencja patentowa (EPC) i praktyka Europejskiego Urzędu Patentowego (EPO)

## O projekcie

To memorandum wyjaśnia, kiedy wynalazek wykorzystujący program komputerowy lub sztuczną inteligencję może uzyskać ochronę patentową w Europie. Omawia różnicę między charakterem technicznym a poziomem wynalazczym, podejście COMVIK oraz decyzję T 2401/22 dotyczącą SAP.

## Najważniejsze wnioski

- Oprogramowanie i AI nie są automatycznie wyłączone z patentowania.
- Samo użycie komputera lub sieci neuronowej nie wystarcza do wykazania poziomu wynalazczego.
- Ważne jest rozwiązanie konkretnego problemu technicznego.
- W sprawie T 2401/22 nie uznano za wystarczające poprawy semantycznej trafności wyszukiwania ani niedostatecznie określonego argumentu o oszczędności zasobów.
- Zastrzeżenia i opis powinny wyjaśniać, które cechy powodują deklarowany efekt techniczny.

## Zawartość

1. Warunki patentowania oprogramowania.
